# Yashika Puri — Portfolio Website

🔗 **Live site:** [yashika051.github.io](https://yashika051.github.io)

Source code for my personal portfolio, showcasing data analytics, BI, and machine learning projects — built from scratch, not a template.

## Featured Projects

| Project | Focus | Stack |
|---|---|---|
| [Superstore Sales Analysis & Data Visualization](https://github.com/Yashika051/CodeAlpha_EDA_SuperstoreSales) | Retail EDA + interactive dashboard | Python, Pandas, NumPy, Plotly, Streamlit |
| [Food Delivery Delay Analysis](https://github.com/Yashika051/Food-Delivery-Delay-Analysis) | Relational DB design + delay pattern analysis | SQL, HTML Dashboard |
| [StaffSense — AI Workforce Management System](https://github.com/Yashika051/StaffSense) | Demand forecasting + explainable AI staffing recommendations | Python, Machine Learning, Streamlit |
| [Hotel Booking Cancellation Analytics Dashboard](https://www.kaggle.com/code/yashikapuri476/hotel-booking-demand) | EDA on 119K+ bookings, cancellation driver analysis | Python, Pandas, Power BI |
| [Green and Intelligent Healthcare](https://github.com/Yashika051/Green-and-Intelligent-Healthcare) | Health risk scoring + carbon footprint estimation | Python, Machine Learning |

Each project has its own detail page on the live site with the full writeup and key findings.

## Site Features

- Custom bold/modern design system
- Clickable project cards linking to dedicated case study pages
- Dark mode toggle
- Fully responsive
- SEO/Open Graph tags
- On-site, print-friendly resume page
- Custom 404 page

## Tech Stack

- **HTML5 / CSS3** — custom design system, CSS variables, no frameworks
- **Vanilla JavaScript** — scroll reveals, dark mode, mobile nav
- **Fonts** — [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque), [Inter](https://fonts.google.com/specimen/Inter), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
- **Hosting** — GitHub Pages
