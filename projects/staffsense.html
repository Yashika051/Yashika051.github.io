StaffSense — AI Workforce Management System

PYTHON · MACHINE LEARNING · STREAMLIT

Nobody trusts a staffing model that just says "trust me." StaffSense forecasts demand and shortages, then actually explains itself.

View repository ↗

Staffing shortages in places like hospitals aren't just inconvenient — they're the kind of problem where a bad guess has real consequences. So this wasn't a project where "the model said so" is an acceptable answer. StaffSense forecasts patient demand and staffing needs, flags likely shortages before they happen, and — critically — shows its reasoning instead of hiding behind a black box.

What I built

  • Built demand forecasting for staffing needs, so shortages can be anticipated instead of discovered mid-shift.
  • Added shortage detection based on projected workload versus available staff.
  • Made the recommendations explainable — the system shows the "why" behind a suggestion, not just the suggestion.
  • Wrapped it all in a Streamlit dashboard so a decision-maker can actually use it, not just a data scientist.

Why it matters

A staffing recommendation nobody trusts is a staffing recommendation nobody follows. Building the explainability in from the start means the people acting on it can actually push back, question it, or override it with confidence — which is what makes an AI tool usable in a high-stakes setting instead of just impressive in a demo.
