06 · MUSIC & AUDIO ANALYTICS

Spotify Track Popularity Analysis

PYTHON · POLARS · DUCKDB · QUARTO

Everyone has a theory about what makes a song popular. This project actually checks — across 114,000 tracks and 114 genres.

View live analysis ↗ View on GitHub ↗

"Popular" music gets talked about a lot, but rarely measured properly. This project treats it as an actual analytical question — pulling apart Spotify's catalog to see how popularity actually distributes, and what it correlates with, instead of relying on gut feeling about what a "hit" sounds like.

What I built

  • Processed and analyzed 114K tracks across 114 genres using Polars and DuckDB for fast, SQL-driven exploration at scale.
  • Examined how popularity is distributed across the catalog — it's not evenly spread, and that shape matters for how you interpret any "average."
  • Broke down genre and artist-level trends to see which categories skew toward higher or lower popularity.
  • Explored relationships between popularity and audio features (like energy, danceability, and tempo) to see which characteristics actually correlate with a track doing well.
  • Published the full analysis as an interactive Quarto report instead of a static notebook, so the findings are actually explorable.

Why it matters

This is as much a data engineering exercise as an analysis one — Polars and DuckDB let the whole pipeline stay fast and SQL-friendly at 114K-row scale, and publishing through Quarto turns a one-off notebook into something a non-technical reader can actually explore and trust.
